# pulse chat

Небольшое чат-приложение на React, Express и PostgreSQL. Интерфейс поддерживает список диалогов, поиск, отправку сообщений и адаптивный режим для мобильных экранов.

## Запуск

1. Заполните переменные PostgreSQL в `.env`.
2. Запустите сервисы:

```bash
docker compose up --build
```

Приложение будет доступно на `http://localhost`. Сообщения сохраняются в таблице `messages`; при первом запуске создаются демонстрационные сообщения.

Для локальной разработки фронтенда:

```bash
cd frontend
npm ci
npm run dev
```
